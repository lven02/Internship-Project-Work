# Internship-Project-Work
This repository contains some of the Python Scripts and Screenshots of the work I completed while working for the University of Southampton as a Software and Hardware Research Assistant
During this 10-week long Internship, I contributed to a Research Project within the Life Sciences department, focussing on Nutritional Science. The project idea resolves around creating a device that will be able to predict the nutrition of consumed food using before and after images of a meal. Upon joining the project, I received a dataset of 717 hospital meals, each with a pair of before and after images alongside data about the meal in a spreadsheet. This data was collected using the second version of the device on a stroke ward of a hospital, across 20 weeks, capturing around 50 patient's data. The spreadsheet contained information about which patient ID is assigned to which meal ID, the date and time, which week of the study this meal was part of, what foods are present within each meal and the weight in grams captured via the device for each image.
